#  Stonksy — Gamified Stock Market Learning Platform


## 🌟 About Stonksy

If Duolingo can gamify learning languages, why can't we gamify learning investing?

**Stonksy** is a gamified paper trading platform designed to help students and first-time investors experience the stock market without risking real money.

The biggest barrier to investing is not money — it's the fear of making the wrong decision.

Stonksy removes that barrier by providing a realistic trading environment where users can simulate buying and selling stocks, manage portfolios, track performance, and understand market behavior safely.

---

## ✨ Features

### 📊 Interactive Dashboard
- Visual representation of portfolio performance
- Real-time portfolio insights
- Holdings and positions tracking

### 💰 Virtual Trading Experience
- Buy and sell stocks using virtual funds
- Track portfolio growth
- Analyze investment decisions without financial risk

### 🛒 Order Management
- Create buy/sell orders
- Maintain transaction history
- Track completed trades

### 🔐 Secure Authentication
- JWT-based authentication
- Protected routes
- User authorization

### 📈 Data Visualization
- Dynamic charts using Chart.js
- Portfolio performance analysis
- Better understanding through visual insights

### ☁️ Production Deployment
- Frontend deployed on Vercel
- Backend deployed on Render
- Cloud database using MongoDB Atlas
